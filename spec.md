# Техническая спецификация — Clinic Wait Time (первая версия)

## Что строим

Прототип сервиса, который показывает пациенту актуальное время приёма по ссылке и на экранах отделений и предупреждает о задержках. Данные выдуманные, внешних систем нет.

## Компоненты

| Компонент | В реальном проекте | В первой версии |
|---|---|---|
| Система записи | Уже есть у клиники | Лист «Записи» в Google Таблице |
| Сервис очереди (ядро) | Сервер + база данных | Лист «Приёмы» + Google Apps Script |
| Модуль прогноза | Часть сервиса | Функция Apps Script по таймеру |
| SMS-модуль | Платный SMS-провайдер | Лист «Журнал SMS», без отправки |
| Регистратура | Модуль в системе клиники | Служебная веб-страница |
| Модуль врача | Окна в рабочей системе врача | Служебная веб-страница |
| Страница пациента | Отдельный хостинг | Веб-страница |
| Экраны отделений | Табло | Веб-страница на отделение |
| Настройки | — | Лист «Настройки» (демо-время, часы работы, числа правил) |

### Данные

**«Записи»** (имитация системы записи): токен приёма, ID пациента, имя пациента (выдуманное), врач, отделение, дата и время создания записи, дата и время приёма, телефон (выдуманный).

**«Врачи»**: врач, отделение, кабинет, начало обеда (между 11.00 и 13.00, обеды распределены равномерно).

**«Приёмы»** (сервис очереди): токен, номер в очереди, дата и время приёма, врач, отделение, длительность приёма, 4 последние цифры телефона, время прихода, фактическое начало, фактическое окончание, прогноз, сообщение для пациента, статус (ожидается, пришёл, идёт, состоялся, отменён, неявка, перенесён).

**«Журнал SMS»**: токен, тип (подтверждение записи, напоминание за 3 дня, напоминание за 1 день, опоздание, задержка), тема, текст, время отправки.

**«Настройки»**: демо-время, длительность приёма по умолчанию (25 минут), часы работы (пн–сб, 8.00–17.00), переключатель «Имитация сбоя» (выключает публикацию, для проверки заглушки).

## Связи

- Система записи → сервис: запись создана, перенесена или отменена. Сервис генерирует номер в очереди и берёт 4 последние цифры телефона.
- Регистратура → сервис: пришёл (с временем), перенёс (новая дата и время в той же записи: токен и номер те же), отменил, не пришёл; начало и окончание приёма (вовремя или время с шагом 5 минут), если вопрос врачу ушёл в регистратуру.
- Сервис → регистратура: список приёмов дня; подсветка, где нужно действие (врач не ответил; опоздание 20+ минут).
- Сервис → модуль врача: пациент пришёл, показать окно.
- Модуль врача → сервис: время начала и окончания приёма.
- Модуль прогноза ↔ сервис: читает факты, записывает прогноз и сообщение.
- Сервис → SMS-модуль: «сообщение типа Х по приёму с токеном Y». SMS-модуль берёт телефон из «Записей» внутри Apps Script и пишет строку в журнал.
- Страница и экраны → сервис: запрос статуса. Страница получает только запись по своему токену.
- Страница → страница-заглушка переноса.

Все модули общаются только через сервис очереди. Регистратура и врач напрямую не общаются.

## Ритм

Цикл 3 минуты от начала работы клиники: в 8.02 пересчёт прогноза, в 8.03 публикация на странице и экранах, дальше каждые 3 минуты. Таймер Apps Script срабатывает каждую минуту и работает только в часы работы клиники.

## Время

Все модули берут текущее время из листа «Настройки»: ячейка пустая — настоящие часы. Заполнена — с этого времени часы идут дальше как обычно: «сейчас» = настоящие часы + сдвиг. На служебной странице кнопка «+3 минуты»: прибавляет 3 минуты к сдвигу и сразу запускает пересчёт и публикацию. Ни один модуль не берёт часы напрямую.

## Сбои

Страница и экраны хранят заглушку у себя. Два цикла подряд (6 минут по демо-времени) без свежих данных → одинаковая заглушка для всех. Для проверки сбоя есть переключатель «Имитация сбоя» в «Настройках».

## Данные и безопасность

- Все данные выдуманные. Таблицы не публикуются.
- Персональные данные (имя, полный телефон) только в «Записях». В сервисе очереди — только 4 последние цифры телефона. Имя пациента видит только модуль врача.
- Ссылка содержит случайный токен (~20 символов). По ссылке видны только номер, врач, отделение, время и статус.
- Секретные ключи — только в Apps Script, не в коде страниц и не на GitHub.
- Служебные страницы (регистратура, врач, служебная панель) открываются только по ссылке с секретным ключом. Ключ хранится в свойствах скрипта Apps Script.
- После 5 неверных токенов с одного устройства доступ блокируется на 5 минут. Устройство опознаётся по метке в браузере (её можно стереть — для прототипа достаточно).

## Автоматические правила

- У того же врача начался более поздний приём не раньше своего назначенного времени → пропущенный закрывается как неявка. Если более поздний приём начался раньше своего времени, неявка не ставится.
- Последний приём дня закрывает регистратура.

## Не входит в первую версию

- Внешний мониторинг (в реальном проекте — готовый сервис).
- Настоящие SMS и мессенджеры: строка в журнале означает «SMS ушло».
- Настоящая система записи и страница записи на приём.
- Перенос записи (только страница-заглушка).
